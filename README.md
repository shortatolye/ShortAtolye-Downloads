# Gökyüzü Haritam — Android uygulaması

Bu dal, Gökyüzü Haritam programının Android uygulamasını derler. Program `app/src/main/assets/index.html` içindedir; uygulama onu tam ekran gösterir.

- Derlenmiş uygulama: `apk/GokyuzuHaritam.apk`
- Her gönderimde GitHub Actions APK'yı yeniden derler, imzayı doğrular ve sonucu `apk/` klasörüne yazar.
- `keystore/` içindeki anahtar yalnızca kişisel kullanım içindir (şifresi derleme dosyasında açıktır). Uygulama Google Play'e konacaksa ayrı ve gizli bir anahtar oluşturulmalıdır.
